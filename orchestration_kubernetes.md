# Orchestration and Kubernetes

## What is Orchestration

Orchestration manages multiple containers automatically.

Tasks include:

Deployment  
Scaling  
Load balancing  
Monitoring

---

# Kubernetes

Kubernetes is a container orchestration platform.

It automates deployment and management of containers.

---

# Key Components

Pod  
Node  
Cluster  
Service

---

# Pod

Smallest deployable unit in Kubernetes.

Contains one or more containers.

---

# Node

A machine that runs pods.

---

# Cluster

Group of nodes managed by Kubernetes.

---

# Benefits

Auto scaling  
Self healing  
Rolling updates  
Service discovery
