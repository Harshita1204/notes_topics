# Firebase Authentication

## Definition
Firebase Authentication is a service that provides authentication for web and mobile apps.

It handles user login and identity management.

---

# Supported Authentication Methods

Email and password  
Google login  
Facebook login  
Phone authentication

---

# Example Workflow

User enters email and password
↓
Firebase verifies credentials
↓
Authentication token generated

---

# Benefits

Easy to implement  
Secure authentication  
Supports multiple login providers
