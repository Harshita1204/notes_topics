TOPIC: NoSQL (Not Only SQL)


1. Definition
------------------------------------------------------------
NoSQL is a type of database that does not use the
traditional relational table structure.

It is designed to handle large volumes of data
and flexible data models.


2. How Data Is Stored
------------------------------------------------------------
NoSQL databases can store data in different formats:

- Document-based (JSON-like documents)
- Key-value pairs
- Column-based
- Graph-based

It does not require a fixed schema.


3. Key Characteristics
------------------------------------------------------------
- Flexible schema.
- Scales horizontally (easy to distribute across servers).
- Designed for high performance and large-scale systems.
- Handles unstructured or semi-structured data well.


4. Examples of NoSQL Databases
------------------------------------------------------------
- MongoDB (Document-based)
- Redis (Key-value)
- Cassandra (Column-based)
- Neo4j (Graph-based)


5. NoSQL vs SQL
------------------------------------------------------------
SQL:
- Structured tables.
- Fixed schema.
- Strong relationships and joins.

NoSQL:
- Flexible structure.
- No fixed schema.
- Better for large-scale distributed systems.


6. When to Use
------------------------------------------------------------
- Big data applications.
- Real-time systems.
- Applications with changing data structure.
- Highly scalable web applications.
