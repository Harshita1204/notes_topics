TOPIC: EC2 (Elastic Compute Cloud)


1. Definition
------------------------------------------------------------
EC2 stands for Elastic Compute Cloud.

It is a cloud computing service provided by Amazon
Web Services (AWS) that allows users to create and
manage virtual servers in the cloud.


2. Purpose of EC2
------------------------------------------------------------
- Run applications on virtual machines.
- Scale computing resources up or down.
- Deploy web servers, APIs, and backend systems.
- Avoid managing physical hardware.


3. How EC2 Works
------------------------------------------------------------
- User selects an instance type (CPU, RAM).
- Chooses operating system (Linux/Windows).
- Launches the instance.
- Connects using SSH or Remote Desktop.
- Installs and runs applications.


4. Key Features
------------------------------------------------------------
- Elastic scaling.
- Pay-as-you-use pricing.
- Secure access using key pairs.
- Integration with other AWS services.


5. Common Use Cases
------------------------------------------------------------
- Hosting websites.
- Running microservices.
- Application deployment.
- Testing and development environments.
