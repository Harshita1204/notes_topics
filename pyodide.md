# Pyodide

## Definition

Pyodide allows Python to run inside the browser using WebAssembly.

This eliminates the need for a Python server.

---

# Features

Runs Python in browser  
Supports scientific libraries  
Works with WebAssembly

---

# Use Cases

Interactive coding environments  
Browser-based notebooks  
Data science in browser

---

# Example

Python code executed directly in browser without backend.
