TOPIC: CPU (Central Processing Unit)


1. Definition
------------------------------------------------------------
CPU stands for Central Processing Unit.

It is the main component of a computer that performs 
all calculations and executes instructions.

In simple terms:
CPU is the brain of the computer.


2. Main Functions of CPU
------------------------------------------------------------
- Executes program instructions
- Performs arithmetic calculations
- Makes logical decisions
- Controls other hardware components

Every task in a computer passes through the CPU.


3. Internal Components of CPU
------------------------------------------------------------

1. Control Unit (CU)
   - Directs operations of the computer
   - Tells memory and other components what to do
   - Fetches instructions from memory

2. Arithmetic Logic Unit (ALU)
   - Performs arithmetic operations (addition, subtraction)
   - Performs logical operations (AND, OR, comparisons)

3. Registers
   - Very small, very fast memory inside CPU
   - Temporarily hold data and instructions being processed

4. Cache Memory
   - Small high-speed memory inside CPU
   - Stores frequently used data
   - Faster than RAM


4. Basic Internal Working (Fetch-Decode-Execute Cycle)
------------------------------------------------------------

CPU works in three main steps:

Step 1: Fetch
   - CPU fetches instruction from RAM.

Step 2: Decode
   - Control Unit interprets what the instruction means.

Step 3: Execute
   - ALU performs the required operation.
   - Result is stored in register or memory.

This cycle happens billions of times per second.


5. Example of CPU Working
------------------------------------------------------------
If you calculate:
5 + 3

Step 1: Instruction is fetched.
Step 2: CPU understands it is an addition operation.
Step 3: ALU performs addition.
Step 4: Result (8) is stored and displayed.


6. CPU Speed
------------------------------------------------------------
CPU speed is measured in Hertz (Hz).

Example:
3.0 GHz means CPU can perform around 
3 billion cycles per second.

More cores allow multiple tasks to run simultaneously.


7. Real-Life Analogy
------------------------------------------------------------
Think of CPU as a manager in an office.

- Control Unit = Manager giving instructions
- ALU = Employee doing calculations
- Registers = Notepad for quick notes
- RAM = Filing cabinet
