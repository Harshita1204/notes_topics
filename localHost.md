TOPIC: LOCALHOST


1. Definition
------------------------------------------------------------
Localhost refers to the local computer that you are
currently using.

It is used to access network services running on
your own machine.


2. IP Address of Localhost
------------------------------------------------------------
The standard IP address for localhost is:

127.0.0.1

This is called the loopback address.

When you use 127.0.0.1, the request never leaves
your computer.


3. Why Localhost Is Used
------------------------------------------------------------
- For development and testing.
- To run local servers.
- To test APIs before deploying to production.
- To simulate a real server environment.

Example:
http://localhost:3000
This means a server is running on port 3000
on your own machine.


4. How It Works
------------------------------------------------------------
When you access localhost:
- Your system sends the request to itself.
- No external network is involved.
- It uses the loopback interface.


5. Difference Between Localhost and Public IP
------------------------------------------------------------
Localhost:
- Accessible only from your computer.
- Used for development.

Public IP:
- Accessible over the internet.
- Used in production environments.
