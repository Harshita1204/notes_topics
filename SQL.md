TOPIC: SQL (Structured Query Language)


1. Definition
------------------------------------------------------------
SQL stands for Structured Query Language.

It is a language used to manage and manipulate
relational databases.

It is used to store, retrieve, update, and delete data.


2. How Data Is Stored
------------------------------------------------------------
Data is stored in tables.

Each table has:
- Rows (records)
- Columns (fields)
- Fixed schema (predefined structure)

Example:
Table: Users

| id | name      | age |
|----|-----------|-----|
| 1  | Rupinder  | 25  |


3. Main Operations in SQL
------------------------------------------------------------
1. SELECT  → Retrieve data
2. INSERT  → Add new data
3. UPDATE  → Modify existing data
4. DELETE  → Remove data

Example:
SELECT * FROM users;


4. Key Features
------------------------------------------------------------
- Structured schema.
- Supports relationships using foreign keys.
- Supports JOIN operations.
- Ensures data integrity using constraints.


5. Examples of SQL Databases
------------------------------------------------------------
- MySQL
- PostgreSQL
- Oracle
- Microsoft SQL Server


6. Advantages
------------------------------------------------------------
- Strong consistency.
- ACID compliance.
- Suitable for structured data.
- Powerful querying capabilities.
