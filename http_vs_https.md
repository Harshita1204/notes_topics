# HTTP vs HTTPS

## HTTP (HyperText Transfer Protocol)

HTTP is a protocol used for transferring web pages.

Characteristics:
- Plain text communication
- No encryption
- Port 80

Risk:
Data can be intercepted.

---

## HTTPS (HTTP Secure)

HTTPS is HTTP with encryption using SSL/TLS.

Features:
- Encrypted communication
- Secure authentication
- Data integrity

Port:
443

---

# HTTPS Security

Uses:

- SSL/TLS encryption
- Digital certificates
- Public key cryptography

---

# Key Differences

| Feature | HTTP | HTTPS |
|------|------|------|
| Encryption | No | Yes |
| Security | Low | High |
| Port | 80 | 443 |
