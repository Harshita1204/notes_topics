# Backend

## Definition
Backend refers to the server-side part of a web application responsible for processing logic, databases, and APIs.

Users interact with the frontend, while backend handles the processing.

---

# Backend Responsibilities

Business logic  
Database management  
Authentication  
API handling

---

# Backend Components

Server  
Application logic  
Database

---

# Example Backend Workflow

User sends request
↓
Server processes request
↓
Database queried
↓
Response returned to user

---

Node.js
