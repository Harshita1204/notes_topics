TOPIC: FILE SYSTEM


1. Definition
------------------------------------------------------------
A file system is the method and structure used by an
operating system to store, organize, and manage files
on storage devices.

It controls how data is saved, retrieved, and structured
on a disk.


2. How It Organizes Data
------------------------------------------------------------
- Uses directories (folders) and subdirectories.
- Stores files in a hierarchical structure.
- Each file has a path (location).

Example:
C:/Users/Rupinder/Documents/file.txt

This path shows the exact location of the file.


3. Main Functions
------------------------------------------------------------
- Creating files and folders.
- Reading and writing files.
- Deleting and modifying files.
- Managing permissions and access control.


4. Types of File Systems
------------------------------------------------------------
- NTFS (Windows)
- FAT32
- ext4 (Linux)
- APFS (Mac)

Different operating systems use different file systems.


5. File System in Programming
------------------------------------------------------------
Programming languages provide modules to interact
with the file system.

Example in Node.js:
The "fs" module allows:
- Reading files
- Writing files
- Creating folders


6. Importance
------------------------------------------------------------
- Organizes data efficiently.
- Prevents data corruption.
- Controls file access and security.
- Essential for operating systems.
