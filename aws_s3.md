# AWS S3 (Simple Storage Service)

## Definition
Amazon S3 is a cloud storage service used to store and retrieve data.

It allows storing files such as:

Images  
Videos  
Documents  
Backups

---

# Key Concepts

Bucket
A container that stores objects.

Object
A file stored in S3.

Key
Unique identifier of an object.

---

# Features

High durability  
Scalable storage  
Secure access control

---

# Common Use Cases

File storage  
Static website hosting  
Data backups
