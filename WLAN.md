TOPIC: WLAN (Wireless Local Area Network)


1. Definition
------------------------------------------------------------
WLAN stands for Wireless Local Area Network.

It is a type of local area network that connects
devices wirelessly using Wi-Fi instead of cables.


2. How WLAN Works
------------------------------------------------------------
- Devices connect through radio signals.
- Uses a wireless router or access point.
- Based on IEEE 802.11 standards.
- Devices communicate within a limited area.


3. Components of WLAN
------------------------------------------------------------
- Wireless Router / Access Point
- Wireless Network Interface Card (NIC)
- Radio frequency signals
- Security protocols (WPA, WPA2, WPA3)


4. Example
------------------------------------------------------------
When you connect your laptop or mobile phone
to home Wi-Fi, you are using a WLAN.

No physical Ethernet cables are required.


5. Advantages
------------------------------------------------------------
- Mobility and flexibility.
- Easy installation.
- No cable dependency.
- Suitable for homes, offices, and campuses.


6. WLAN vs LAN
------------------------------------------------------------
LAN:
- Uses physical cables (Ethernet).
- More stable and secure.

WLAN:
- Uses wireless signals.
- Provides mobility and convenience.
