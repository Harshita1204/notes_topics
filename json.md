# JSON (JavaScript Object Notation)

## Definition
JSON is a lightweight data format used for data exchange between systems.

It is easy for humans to read and easy for machines to parse.

---

# Example JSON

{
  "name": "Alice",
  "age": 25,
  "city": "Delhi"
}

---

# JSON Structure

JSON uses:

Key-value pairs

Example:

"key": "value"

---

# Advantages

Lightweight  
Language independent  
Easy to parse  
Widely supported

---

# Use Cases

API communication  
Configuration files
