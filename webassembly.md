# WebAssembly (WASM)

## Definition

WebAssembly is a binary instruction format designed for high performance execution in web browsers.

It allows code written in languages like C, C++, and Rust to run in the browser.

---

# Advantages

Near native performance  
Secure sandbox environment  
Language flexibility

---

# Use Cases

Game engines  
Video editing tools  
Machine learning in browser

---

# How it Works

Source code → Compile to WebAssembly → Run in browser runtime
