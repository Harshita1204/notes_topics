# REST API

## Definition
REST (Representational State Transfer) is an architectural style used to design networked applications.

REST APIs allow communication between clients and servers using HTTP.

---

# Example

Client request:

GET /users

Server response:

{
  "id": 1,
  "name": "Alice"
}

---

# HTTP Methods

GET → Retrieve data  
POST → Create data  
PUT → Update data  
DELETE → Remove data

---

# REST Principles

Stateless communication  
Resource-based URLs  
Standard HTTP methods

---

# Example URL

/api/users/1

This represents a specific user resource.
