TOPIC: RAM (Random Access Memory)


1. Definition
------------------------------------------------------------
RAM stands for Random Access Memory.

It is the temporary memory of a computer used to store 
data and programs that are currently in use.

In simple terms:
RAM is the working memory of a computer.


2. Why RAM Is Needed
------------------------------------------------------------
When you open an application:
- The program is loaded from storage (HDD/SSD)
- It is placed into RAM
- The CPU accesses it from RAM for faster processing

RAM is much faster than hard disk storage.
Without RAM, the system would be extremely slow.


3. Key Characteristics of RAM
------------------------------------------------------------
- Temporary (Volatile memory)
- Data is lost when power is turned off
- Fast access speed
- Used for active processes only


4. How RAM Works
------------------------------------------------------------
Step 1: You open a program.
Step 2: The system loads program data into RAM.
Step 3: CPU reads and writes data from RAM.
Step 4: When program closes, RAM space is freed.

More RAM allows:
- More applications to run simultaneously
- Better system performance
- Faster multitasking


5. Types of RAM
------------------------------------------------------------

1. SRAM (Static RAM)
   - Faster
   - More expensive
   - Used in CPU cache

2. DRAM (Dynamic RAM)
   - Slower than SRAM
   - Less expensive
   - Used as main system memory


6. RAM vs Storage
------------------------------------------------------------

RAM:
- Temporary
- Fast
- Used while system is running

Storage (HDD/SSD):
- Permanent
- Slower than RAM
- Stores files, OS, applications


7. Real-Life Analogy
------------------------------------------------------------
Think of RAM as a study table.

Storage = Book shelf
RAM = Study table

You take books from shelf and place them on table 
to work quickly.

When work is done, books are removed from table.
