TOPIC: CLOUD COMPUTING


1. Definition
------------------------------------------------------------
Cloud computing is the delivery of computing services
such as servers, storage, databases, and networking
over the internet instead of using local hardware.

It allows users to access resources on demand.


2. Key Features
------------------------------------------------------------
- On-demand resource availability.
- Scalability (increase or decrease resources easily).
- Pay-as-you-use pricing model.
- No need to manage physical infrastructure.


3. Types of Cloud Services
------------------------------------------------------------
1. IaaS (Infrastructure as a Service)
   Provides virtual machines and storage.
   Example: AWS EC2.

2. PaaS (Platform as a Service)
   Provides development platforms.
   Example: Heroku.

3. SaaS (Software as a Service)
   Provides ready-to-use software.
   Example: Gmail.


4. Deployment Models
------------------------------------------------------------
- Public Cloud (shared infrastructure).
- Private Cloud (dedicated to one organization).
- Hybrid Cloud (combination of public and private).


5. Benefits
------------------------------------------------------------
- Reduced infrastructure cost.
- High availability.
- Global accessibility.
- Automatic updates and maintenance.


6. Examples of Cloud Providers
------------------------------------------------------------
- Amazon Web Services (AWS)
- Microsoft Azure
- Google Cloud Platform (GCP)
