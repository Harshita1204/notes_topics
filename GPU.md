TOPIC: GPU (Graphics Processing Unit)


1. Definition
------------------------------------------------------------
GPU stands for Graphics Processing Unit.

It is a specialized processor designed to handle 
graphics rendering and parallel computations.

In simple terms:
GPU is responsible for creating images, videos, 
and visual output on your screen.


2. Why GPU Is Needed
------------------------------------------------------------
CPU can process tasks, but it is not optimized 
for handling large graphical computations.

GPU is designed to:
- Render images and videos
- Process 3D graphics
- Handle heavy parallel calculations
- Support gaming and AI workloads

It improves performance for graphics-intensive tasks.


3. Key Difference Between CPU and GPU
------------------------------------------------------------

CPU:
- Few powerful cores
- Good for sequential tasks
- Handles general-purpose computing

GPU:
- Thousands of smaller cores
- Good for parallel tasks
- Optimized for graphics and large computations


4. Internal Working (Basic Concept)
------------------------------------------------------------
GPU works using parallel processing.

Instead of processing one task at a time,
it processes many small tasks simultaneously.

Example:
When rendering a 3D image:
- The image is divided into thousands of small pixels.
- GPU calculates color and lighting for each pixel at the same time.
- Final image is displayed on screen.

This makes graphics processing much faster.


5. Main Components of GPU
------------------------------------------------------------

1. CUDA Cores / Stream Processors
   - Perform parallel calculations

2. VRAM (Video RAM)
   - Memory dedicated to graphics data

3. Shader Units
   - Handle shading, lighting, and effects


6. Where GPU Is Used
------------------------------------------------------------
- Gaming
- Video editing
- 3D rendering
- Artificial Intelligence
- Machine Learning
- Cryptocurrency mining


7. Real-Life Analogy
------------------------------------------------------------
Think of CPU as a single skilled worker.

Think of GPU as a team of thousands of workers 
doing small tasks at the same time.

If one large task is divided into many small parts,
GPU completes it faster.
