# Docker

## Definition
Docker is a platform used to develop, package, and run applications inside containers.

It ensures applications run consistently across different environments.

---

# Why Docker is Used

Problem:

Developers often face the issue:

"It works on my machine but not on the server."

Docker solves this by packaging:

- Application code
- Dependencies
- Libraries
- Runtime

into one container.

---

# Key Components

## Dockerfile
Script that defines how to build a container image.

## Docker Image
A blueprint used to create containers.

## Docker Container
A running instance of a Docker image.

---

# Workflow

Code → Dockerfile → Docker Image → Container

---

# Benefits

Environment consistency  
Easy deployment  
Scalability  
Isolation
