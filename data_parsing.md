# Data Parsing

## Definition
Data parsing is the process of analyzing structured data and converting it into a usable format for programs.

---

# Example

Input Data (JSON):

{
  "name": "Alice",
  "age": 25
}

Parsed Data in Python:

name = data["name"]

---

# Why Parsing is Important

Extract useful information  
Transform data between formats  
Enable communication between systems
