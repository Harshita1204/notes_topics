# AWS EC2 (Elastic Compute Cloud)

## Definition
Amazon EC2 provides virtual servers in the cloud.

These servers are called **instances**.

---

# What EC2 Allows

Run applications  
Host websites  
Deploy backend services

---

# Key Features

Scalable computing capacity  
Multiple instance types  
Full control over server environment

---

# Example

Developer launches an EC2 instance and installs:

Linux  
Node.js  
Database
