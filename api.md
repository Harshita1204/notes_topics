TOPIC: API (Application Programming Interface)

1. Definition
------------------------------------------------------------
API stands for Application Programming Interface.

An API is a mechanism that allows two software applications 
to communicate with each other.

It acts as an intermediary between a client and a server.

Simple Meaning:
API is a bridge that allows one system to request data or 
services from another system.

------------------------------------------------------------

2. Basic Concept
------------------------------------------------------------
API works on the Request–Response model.

Step 1: Client sends a request.
Step 2: Server processes the request.
Step 3: Server sends a response.
Step 4: Client receives and displays the response.

The client does not directly access the database or internal 
logic of the server. It communicates only through the API.

------------------------------------------------------------

3. Real-Life Analogy
------------------------------------------------------------
Restaurant Example:

Customer      → Client
Waiter        → API
Kitchen       → Server

The customer gives an order to the waiter.
The waiter takes the order to the kitchen.
The kitchen prepares the food.
The waiter brings the food back.

The waiter acts as a middle layer, just like an API.

------------------------------------------------------------

4. Practical Example
------------------------------------------------------------
When you use:
- A weather app
- Online payments
- Social media login
- Google Maps

The application sends a request to a server using an API.
The server returns data in structured format (usually JSON).

Example:
When opening a product page:
- App sends request to server API
- Server sends product data
- App displays product details

------------------------------------------------------------

5. Data Format Used in APIs
------------------------------------------------------------
Most APIs exchange data in:

1. JSON (JavaScript Object Notation) 
2. XML (Extensible Markup Language)

Example of JSON:
{
  "name": "Harshu",
  "age": 21
}

------------------------------------------------------------

6. Types of APIs
------------------------------------------------------------
1. Web API
   Used over the internet.
   Example: REST API

2. Library API
   Functions provided by programming libraries.

3. Operating System API
   Allows applications to interact with the OS.

------------------------------------------------------------

7. Importance of APIs
------------------------------------------------------------
- Connect frontend and backend
- Enable communication between systems
- Allow third-party integrations
- Improve modularity
- Reduce development time
- Enhance scalability

Without APIs, modern web and mobile applications 
cannot function efficiently.
