# Automated Machine Learning (AutoML)

## Definition

AutoML automates the process of building machine learning models.

It reduces the need for manual ML expertise.

---

# Key Tasks Automated

Feature engineering  
Model selection  
Hyperparameter tuning  
Model evaluation

---

# Workflow

Dataset → AutoML system → Best ML model

---

# Advantages

Faster model development  
Accessible to non-experts  
Improved model optimization

---

# Popular AutoML Tools

Google AutoML  
Auto-sklearn  
H2O AutoML

---

# Example Use Case

Predicting customer churn.

AutoML automatically tests models like:

Random Forest  
Gradient Boosting  
Neural Networks
