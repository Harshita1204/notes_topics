TOPIC: STRUCTURED DATABASE


1. Definition
------------------------------------------------------------
A structured database is a database where data is stored
in a predefined format using tables with rows and columns.

It follows a fixed schema and is commonly called a
relational database.


2. How Data Is Organized
------------------------------------------------------------
- Data is stored in tables.
- Each table has rows (records).
- Each table has columns (fields).
- Structure must be defined before inserting data.

Example:
Table: Employees

| id | name     | department |
|----|----------|------------|
| 1  | Harshita | art        |


3. Key Characteristics
------------------------------------------------------------
- Fixed schema (structure defined in advance).
- Strong relationships using primary and foreign keys.
- Supports JOIN operations.
- Ensures data consistency using constraints.


4. Examples
------------------------------------------------------------
- MySQL
- PostgreSQL
- Oracle
- Microsoft SQL Server


5. Advantages
------------------------------------------------------------
- High data integrity.
- ACID compliance.
- Suitable for structured and transactional data.
- Strong support for complex queries.


6. Structured DB vs Unstructured
------------------------------------------------------------
Structured DB:
- Organized in tables.
- Schema required.
- Best for transactional systems.

Unstructured / NoSQL:
- Flexible format.
- No fixed schema.
- Better for scalable and dynamic data.
