TOPIC: JSON FILE


1. Definition
------------------------------------------------------------
JSON stands for JavaScript Object Notation.

A JSON file is a lightweight data format used to store
and exchange structured data between systems.

It is human-readable and easy for machines to parse.


2. Structure of JSON
------------------------------------------------------------
JSON stores data in key-value pairs.

Example:

{
  "name": "Rupinder",
  "age": 25,
  "city": "Delhi"
}

- Keys are strings.
- Values can be string, number, boolean, array, object, or null.


3. Why JSON Is Used
------------------------------------------------------------
- Common format for APIs.
- Easy to read and write.
- Lightweight compared to XML.
- Supported by almost all programming languages.


4. Where JSON Files Are Used
------------------------------------------------------------
- API request and response data.
- Configuration files.
- Storing structured data.
- Data exchange between frontend and backend.


5. JSON vs JavaScript Object
------------------------------------------------------------
JSON:
- Text format.
- Keys must be in double quotes.
- Used for data transfer.

JavaScript Object:
- Exists in memory.
- Can use single quotes or no quotes for keys.
- Used inside code.
