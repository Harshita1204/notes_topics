# Amazon CloudFront

## Definition
CloudFront is a Content Delivery Network (CDN) provided by AWS.

It distributes content across global edge servers to reduce latency.

---

# How It Works

User requests content
↓
Nearest edge server responds

---

# Benefits

Faster content delivery  
Reduced server load  
Improved user experience

---

# Example Use Cases

Video streaming  
Static websites  
API acceleration
