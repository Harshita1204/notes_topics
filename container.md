# Container

## Definition
A container is a lightweight package that includes an application and its dependencies.

Containers run consistently across different computing environments.

---

# How Containers Work

Containers share the host operating system but remain isolated.

This makes them lightweight compared to virtual machines.

---

# Container Components

Application code  
Libraries  
Dependencies  
Runtime environment

---

# Containers vs Virtual Machines

Containers share OS kernel.  
Virtual machines run full operating systems.
