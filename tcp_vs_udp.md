# TCP vs UDP

## TCP (Transmission Control Protocol)

TCP is a **connection-oriented protocol** that ensures reliable
data delivery.

Features:
- Ordered delivery
- Error checking
- Retransmission
- Flow control

Example Use Cases:
- Web browsing (HTTP/HTTPS)
- Email
- File transfer

---

## UDP (User Datagram Protocol)

UDP is a **connectionless protocol** designed for speed.

Features:
- No handshake
- No guaranteed delivery
- Low latency

Example Use Cases:
- Video streaming
- Online gaming
- DNS queries

---

# Key Differences

| Feature | TCP | UDP |
|------|------|------|
| Connection | Yes | No |
| Reliability | High | Low |
| Speed | Slower | Faster |
| Packet order | Guaranteed | Not guaranteed |
| Error recovery | Yes | No |
