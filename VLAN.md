TOPIC: VLAN (Virtual Local Area Network)


1. Definition
------------------------------------------------------------
VLAN stands for Virtual Local Area Network.

It is a method of dividing a physical network into
multiple logical networks within the same switch.


2. Purpose of VLAN
------------------------------------------------------------
- Improves network security.
- Reduces broadcast traffic.
- Organizes devices by department or function.
- Enhances network performance.


3. How VLAN Works
------------------------------------------------------------
Even if all computers are connected to the same
physical switch, VLAN allows them to be separated
logically.

Devices in one VLAN cannot communicate with devices
in another VLAN unless routing is configured.


4. Example
------------------------------------------------------------
In an office:

- HR Department → VLAN 10
- IT Department → VLAN 20
- Accounts → VLAN 30

Although connected to the same switch,
each department acts as a separate network.


5. Key Characteristics
------------------------------------------------------------
- Operates at Layer 2 (Data Link Layer).
- Configured on network switches.
- Requires a router or Layer 3 switch
  for inter-VLAN communication.
- Identified using VLAN IDs.


6. Benefits
------------------------------------------------------------
- Better traffic control.
- Increased security.
- Logical grouping without changing hardware.
- Efficient network management.
