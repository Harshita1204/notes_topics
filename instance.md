TOPIC: INSTANCE


1. Definition
------------------------------------------------------------
An instance is a running virtual machine in the cloud.

It is a server created using cloud services like AWS EC2,
Azure VM, or Google Compute Engine.


2. What an Instance Contains
------------------------------------------------------------
- CPU (processing power)
- RAM (memory)
- Storage (disk space)
- Operating system (Linux/Windows)

It behaves like a normal physical computer,
but runs virtually in the cloud.


3. How It Works
------------------------------------------------------------
- You choose an instance type (size and power).
- The cloud provider allocates resources.
- The instance starts running.
- You can connect to it using SSH or Remote Desktop.


4. Key Features
------------------------------------------------------------
- Can be started, stopped, or terminated.
- Scalable (resize resources).
- Pay only while running.
- Fully customizable environment.


5. Example
------------------------------------------------------------
When you launch a server in AWS EC2,
that running server is called an EC2 instance.
