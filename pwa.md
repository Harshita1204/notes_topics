# Progressive Web App (PWA)

## Definition
A Progressive Web App is a web application that behaves like a native mobile application while running in a web browser.

PWAs use modern web technologies to provide an app-like experience.

---

# Key Features

## Offline Capability
PWAs can work offline using **Service Workers**.

## Installable
Users can install PWAs on their devices like normal apps.

## Fast Loading
Uses caching to load quickly.

## Responsive Design
Works on desktop, tablet, and mobile.
