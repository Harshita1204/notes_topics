# Communication Protocols

## Definition
Communication protocols are rules that allow devices and systems to communicate over a network.

They define how data is transmitted and received.

---

# Common Protocols

## HTTP
Used for web communication.

## HTTPS
Secure version of HTTP with encryption.

## TCP
Reliable transport protocol ensuring data delivery.

## UDP
Faster but less reliable protocol.

## WebSocket
Enables real-time two-way communication.

---

# Protocol Stack Example

Application Layer → HTTP  
Transport Layer → TCP  
Network Layer → IP

---

# Why Protocols Are Important

Ensure compatibility between systems  
Define communication rules  
Enable secure and reliable data transfer
